# Analytics and reports

Dashboard and Reports are read-only views of the existing circulation snapshot and member directory. The v2 circulation key remains authoritative. Existing demonstration transactions are included in the totals. Phase 4 generates no example transactions.

Snapshot metrics reflect the latest successfully loaded records. Open loans include due-today and overdue loans. The circulation chart separates overdue open loans from other open loans and displays all-time returned loans as a separate group. The trend charts and popularity use the selected local calendar period. Issues and returns are counted on their own dates, assessments use the local assessment date, and payments use the recorded payment date. Seven- and 30-day views use daily buckets. The 90-day view uses consecutive seven-day buckets, with a shorter final bucket when needed.

Financial reports distinguish active accrual estimates, period-based assessments and payments, and current assessed balances. Payment totals sum the immutable transaction rows once. CSV exports all matching rows and expresses monetary columns in INR with two decimal places. The print layout includes the same matching records, summaries, and filter selections. Use the browser's print dialog to save a PDF.

Activity history contains events previously recorded by circulation and inventory workflows. Member registrations recorded from Phase 4 onward are written with the member update and survive eligible member deletion. Existing members do not receive fabricated registration events. Older deleted books may be shown by ID in inventory activity if the event contains no title and there is no current book record. Historical circulation and financial reports use recorded book and member snapshots. Popularity uses historical titles when needed. Author and category for deleted titles are unavailable unless present in the current inventory, so the popularity report groups those records under Unknown.
